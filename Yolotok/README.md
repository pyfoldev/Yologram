# Йолоток

Мод для TikTok на Android: Material Design 3, смена региона, обход блокировок
через свой прокси и продление огонька. Собирается из официального APK патчами из
этого репозитория, исходники TikTok сюда не входят.

Основан на [TikTok Mi](https://github.com/fuckramochka/tiktokmi) (fuckramochka),
который основан на [MargyT](https://github.com/narezany/MargyT) (narezany).
Это модифицированная версия, она **не** выпущена авторами оригинала.
Условия — GPL-3.0 и [ADDITIONAL-TERMS.md](ADDITIONAL-TERMS.md).

## Что есть

- **Material 3 с первого запуска.** Крупные скруглённые карточки, ползунки и
  переключатели M3, капсула навигации, чёрный AMOLED-фон, акцент фиолетовый
  `#7C4DFF`. Настройки в *Настройки и конфиденциальность → Йолоток*.
- **Смена региона.** Страна SIM, оператор и MCC/MNC подменяются (список из 30+ стран).
- **Обход блокировок.** Трафик приложения идёт через ваш HTTP- или SOCKS5-прокси
  (`Йолоток → Обход блокировок`). Прокси в мод не вшит, адрес вводите сами.
  Действует на Java-сеть и OkHttp, а нативный сетевой стек подхватывает его через
  системные свойства прокси; полной гарантии для него нет, при сбоях перезапустите
  TikTok. Без аутентификации по логину и паролю.
- **Огонёк.** Автоотправка стикера в чаты, где серия вот-вот сгорит (раз в сутки на чат).
- Плюс всё, что было в TikTok Mi: удаление рекламы, видео без водяного знака, призрак и т.д.

Серверы прежнего автора (значки, обновления, отчёты о сбоях, котики) отключены:
мод не обращается к ним.

## Сборка

Нужен универсальный APK TikTok (arm64, не bundle), JDK и Python 3:

    ./build.sh path/to/tiktok.apk                  # акцент #7C4DFF по умолчанию
    ./build.sh path/to/tiktok.apk --accent 7C4DFF

Готовый файл: `build/tiktokmi.apk`. Тесты: `python3 -m unittest discover tests`.
APK TikTok в репозитории нет и не будет.

TikTok вместе с модом ставится вместо оригинала (пакет `com.zhiliaoapp.musically`).
