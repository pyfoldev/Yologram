# ID-бот

Бот для Telegram: узнать свой ID, ID по `@username`, по контакту, по ссылке, по пересланному
сообщению; открыть профиль/чат по ID; оценить дату регистрации аккаунта. Все действия — на inline-кнопках.

## Управление
- Постоянная клавиатура внизу (кнопки «Мой ID», «По username», «Выбрать пользователя/группу/канал» и т.д.).
- Меню команд «/» с описаниями (регистрируется при старте через `set_my_commands`).
- Русские команды без слеша: `мой id`, `по username`, `по контакту`, `по ссылке`, `открыть по id`,
  `дата регистрации`, `меню`, `помощь`, `отмена` (регистр и эмодзи не важны).

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN
export $(grep -v '^#' .env | xargs) && python main.py
```

## Эмодзи-пак
При старте бот читает пак `EMOJI_PACK` (`solutions_project_by_Solutmark_bot`) и подставляет
кастомные эмодзи в текст (`<tg-emoji>`) и иконки кнопок (`icon_custom_emoji_id`), подбирая
по символу эмодзи стикера. Если Telegram их не принимает — автоматически падает на обычные.
Ручная привязка: `emoji_map.json` вида `{"id": "<custom_emoji_id>", "date": "..."}`;
ключи — `id user group channel date link contact search ok warn back me star`.
`/emojis` (админ) показывает найденные в паке эмодзи.

## Дата регистрации
Telegram её не отдаёт. Дата оценивается интерполяцией по ID между опорными точками
(`regdate.py`). Точность — месяцы; поздние точки приблизительные. Улучшить: админ шлёт
`/anchor <id> <ГГГГ-ММ-ДД>` для аккаунта с известной датой — точки пишутся в `anchors.json`.

## Ограничения Bot API
- Username → ID работает для публичных username; ID → профиль открывается ссылкой `tg://user?id=`.
- Приглашения `t.me/+…` бот расшифровать не может — перешли сообщение из чата или выбери чат кнопкой.
- Кастомные эмодзи в тексте бота Telegram показывает не всем ботам; иконки кнопок — тоже по условиям Telegram.
