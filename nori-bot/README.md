# Nori — бизнес-бот для Telegram

Бот для **Telegram Business**: подключается к вашему аккаунту (Настройки → Business → Чат-боты) и работает внутри ваших личных чатов.

## Что умеет

| | |
|---|---|
| 🗑 **Удалённые сообщения** | собеседник удалил сообщение или медиа — оно приходит вам в личку с ботом |
| ✏️ **Правки** | «Было / Стало» при изменении сообщения |
| 🔥 **Исчезающее медиа** | фото, видео, кружки и голосовые собеседника сразу копируются вам в личку; `.save` ответом на медиа — достать вручную |
| 🔇 **Мут** | `.mute 1ч` — сообщения собеседника удаляются на лету, `.unmute` / кнопка в меню |
| 🤖 **Автоответчик** | всегда или по расписанию (`22:00–09:00`), антиспам-интервал, молчит, если вы сами только что писали, `{name}` в тексте |
| 🎮 **Мини-игры** | крестики-нолики, камень-ножницы-бумага, блэкджек, сапёр, угадай число, викторина, орёл/решка, слоты + монеты, бонус, топ |
| ⚔️ **Игры вдвоём** | `@имя_бота` в любом чате → крестики-нолики / КНБ с кнопками |

Ещё: 🔑 триггеры по ключевым словам · 📝 шаблоны (`.t имя`) · ⏰ напоминания (`.remind 30м …`) · ⭐ VIP-чаты · 🧮 `.calc` · ⌨️ анимация печати `.type` и `.love` · 🎲 `.dice` · `.mock` · `.stats` · `.log` (последние удалённые) · настройки через `/start`.
Все команды начинаются с точки и пишутся вами в любом бизнес-чате; список — `.help`.

Премиум-эмодзи — набор [Solutions Project](https://t.me/addemoji/solutions_project_by_Solutmark_bot): подставляются автоматически вместо обычных (`nori/emoji_map.json`, пересборка — `python tools/build_emoji_map.py`).
Если Telegram не принимает их для вашего бота, сообщение уходит с обычными эмодзи.

## Запуск

1. @BotFather → создать бота → **Bot Settings → Business Mode → включить**.
2. `cp .env.example .env`, вписать `BOT_TOKEN`.
3. `pip install -e .` и `python -m nori`.
4. В Telegram: Настройки → Business → Чат-боты → выбрать бота. Для мута дайте право «Удалять любые сообщения», для чистки команд — «Удалять свои».

Тесты: `pip install -e .[dev] && pytest`.

## Ограничения Telegram

- Бот видит только то, что Telegram присылает бизнес-ботам; сообщения, удалённые **до** подключения, и сообщения старше 14 дней (чистка кэша) не вернуть.
- Исчезающее (view-once) медиа не помечено в Bot API, поэтому «ловится» копированием всего входящего фото/видео/кружков/голосовых; если файл Telegram отдаёт боту не всегда, используйте `.save` ответом на сообщение. Отключается в меню.
- Игры с кнопками работают в личке с ботом и через инлайн; кнопки внутри самих бизнес-чатов Telegram ботам не отдаёт.
