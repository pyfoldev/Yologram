# Anonbot — анонимный чат в Telegram

Бот соединяет двух незнакомцев. Имена и username не раскрываются (сообщения копируются ботом).

## Возможности
- Меню команд (кнопка «≡» у поля ввода, `set_my_commands`) и нижняя клавиатура: «🚀 Начать диалог», «🔎 Поиск по полу», «📖 Интересы поиска»; в диалоге — «Следующий», «Завершить», «Звонок», «Видео», «Игры»
- Русские команды без слеша (сообщение целиком): `поиск`, `следующий`, `стоп`, `звонок`, `видео`, `игры`, `интересы`, `пол`, `настройки`, `помощь`. В диалоге такое сообщение считается командой и собеседнику не уходит
- `/search` — начать поиск · `/next` — следующий собеседник · `/stop` — завершить диалог / остановить поиск
- Поиск по полу (кого ищу) и по интересам (`/settings`); если по интересам долго никого нет — через 25 с фильтр ослабляется
- Пересылка текста, фото, видео, голосовых, стикеров, файлов и т.д.
- `/call` и `/video` — звонок через браузер: собеседник подтверждает, оба получают кнопку-ссылку (WebRTC, сигналинг на сервере бота)
- `/games` — крестики-нолики, камень-ножницы-бумага, кости, правда/действие

## Запуск
```bash
cd anonbot
pip install -r requirements.txt
cp .env.example .env   # впиши BOT_TOKEN и BASE_URL
python bot.py
```
**BASE_URL** должен быть публичным **HTTPS** (браузер не даёт доступ к микрофону/камере по http).
Для теста: `cloudflared tunnel --url http://localhost:8080` или ngrok, либо nginx + Let's Encrypt, проксируя на `WEB_PORT` (WebSocket `/ws/` тоже).

## Приватность звонков
WebRTC соединяет напрямую (P2P), поэтому собеседник технически может узнать IP. Чтобы скрыть:
поднимите TURN (coturn) и задайте `TURN_URL`, `TURN_USER`, `TURN_PASS`, `FORCE_RELAY=1`.
Бот предупреждает об этом при запросе звонка.

## Ограничения
Очередь и активные диалоги хранятся в памяти (после перезапуска сбрасываются); настройки пользователей — в SQLite (`anonbot.sqlite3`). Один процесс бота.

## Кастомные эмодзи
Бот при старте загружает пак [solutions_project_by_Solutmark_bot](https://t.me/addemoji/solutions_project_by_Solutmark_bot)
(`EMOJI_PACK` в `.env` — другой пак) и подменяет обычные эмодзи в текстах бота на кастомные из пака
(сопоставление по эмодзи, на который назначен стикер). Telegram разрешает кастомные эмодзи в сообщениях
бота только если у бота куплен дополнительный username на Fragment; иначе показываются обычные.
В кнопках (в т.ч. нижней клавиатуре) кастомные эмодзи недоступны.
