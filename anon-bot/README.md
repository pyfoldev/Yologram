# Бот анонимных сообщений

1. Создай бота у [@BotFather](https://t.me/BotFather), получи токен.
2. `cp .env.example .env`, впиши `BOT_TOKEN`.
3. Запуск:
   ```
   pip install -r requirements.txt
   set -a; . ./.env; set +a
   python bot.py
   ```
4. Напиши боту `/start` — получишь личную ссылку `t.me/<бот>?start=<код>`, поставь её в профиль.

Кто перейдёт по ссылке — пишет любое сообщение (текст, фото, видео, голосовое, стикер), тебе оно
приходит анонимно с кнопками **Ответить** / **Заблокировать**. В меню: ссылка, «Поделиться»,
статистика, «Новая ссылка» (старая перестаёт работать).

Кастомные эмодзи берутся из набора `solutions_project_by_Solutmark_bot` при старте бота
(в тексте и иконками на кнопках). Если Telegram не разрешает их вашему боту, бот сам откатится
на обычные эмодзи. Выключить иконки на кнопках: `BUTTON_EMOJI=0`.

## Команды
Работают тремя способами: кнопками внизу экрана, из меню «/» (команды регистрируются сами)
и обычным текстом на русском без слэша: `моя ссылка`, `поделиться`, `статистика`,
`новая ссылка`, `меню`, `помощь`, `отмена`. Регистр и эмодзи не важны.
Во время написания анонимки перехватывается только «Отмена» — остальные слова уходят как сообщение.

## Кастомные эмодзи не показываются?
Команда `/emoji` в боте покажет, загрузился ли набор, и пришлёт тест. По правилам Telegram бот
может слать кастомные эмодзи (в тексте и на кнопках), только если **у аккаунта, создавшего бота
в @BotFather, есть Telegram Premium** (либо у бота куплен доп. username на Fragment).
Иначе Telegram молча показывает обычный эмодзи. Другая «лапка» из набора: `PAW_EMOJI_ID=<id>`.
