# Sticker/Emoji bot

Бот делает стикеры и премиум-эмодзи (custom emoji) со своим текстом: 200 шаблонов (25 предметов × 8 цветов), рисуются кодом.

```
pip install -r requirements.txt
export BOT_TOKEN=...   # от @BotFather
python bot.py
```

Поток: /start → тип → шаблон по номеру → текст → «Добавить в мой набор» (создаётся личный набор пользователя).
Эмодзи-наборы вставлять в сообщения могут пользователи с Telegram Premium. Свой шрифт: `FONT_PATH=/путь/к.ttf`.
