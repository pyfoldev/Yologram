# Павлодар Транспорт (Android)

Карта OpenStreetMap (osmdroid), автобусы и трамваи в реальном времени, автоопределение ближайшей остановки по GPS,
список «кто едёт к вам и куда» с ETA, фильтр по маршрутам.

Сборка: `echo sdk.dir=<путь к SDK> > local.properties && gradle :app:assembleDebug`

## Источники данных — важно
- Публичного API позиций транспорта у 2GIS, go2bus.kz и avtobys.kz найти не удалось (2GIS — по ключу/договору, у остальных API не документирован).
- По умолчанию работает **ДЕМО** (симуляция на примерных маршрутах).
- Реальные данные: нажмите на плашку источника вверху карты и укажите URL JSON (формат — в `data/Providers.kt`, `RemoteJsonProvider`).
  Адаптер под конкретный сервис добавляется там же, когда известны эндпоинты/ключи.
