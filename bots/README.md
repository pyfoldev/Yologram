# 🤖 10 шаблонных Telegram-ботов (Python + aiogram 3)

Каждый бот — **один небольшой файл** с комментариями на русском. Все используют общее
ядро `core/` (токен, запуск, база данных), поэтому код в самих ботах — только логика.

| № | Файл | Тип | Чему учит |
|---|------|-----|-----------|
| 1 | `bot01_menu.py` | Меню / визитка | reply- и инлайн-клавиатуры, навигация редактированием сообщения |
| 2 | `bot02_quiz.py` | Викторина | состояние игры, callback с параметрами, подсчёт очков |
| 3 | `bot03_todo.py` | Список дел | команды с аргументами, SQLite, данные у каждого пользователя свои |
| 4 | `bot04_reminder.py` | Напоминания | фоновые задачи asyncio, разбор «30m», восстановление после перезапуска |
| 5 | `bot05_form.py` | Анкета / заявка | FSM (машина состояний), валидация, отправка админам |
| 6 | `bot06_support.py` | Поддержка | пересылка «пользователь ↔ админ» через Reply |
| 7 | `bot07_moderator.py` | Модератор группы | удаление спама, варны, бан, права админов |
| 8 | `bot08_info.py` | Погода и курсы валют | асинхронные HTTP-запросы, обработка ошибок API |
| 9 | `bot09_shop.py` | Магазин | каталог, корзина, оформление заказа |
| 10 | `bot10_ai.py` | ИИ-ассистент (Claude) | память диалога, «печатает…», разбивка длинных ответов |

## Быстрый старт

```bash
cd bots
python -m venv .venv && source .venv/bin/activate   # по желанию
pip install -r requirements.txt

cp .env.example .env          # впишите BOT_TOKEN от @BotFather
cd ..                         # запускать из корня репозитория
python -m bots.bot01_menu     # или bot02_quiz, bot03_todo, ...
```

Один токен = один запущенный бот. Для другого бота создайте нового в @BotFather
или остановите предыдущий (Ctrl+C).

## Как устроен любой бот

```python
router = Router()                       # 1. «Контейнер» обработчиков

@router.message(Command("start"))       # 2. Фильтр: когда сработать
async def start(message: Message):      # 3. Хендлер — обычная async-функция
    await message.answer("Привет!")

if __name__ == "__main__":
    run_bot(router)                     # 4. Запуск (long polling)
```

Основные «кубики»:
- `@router.message(...)` — входящие сообщения, `@router.callback_query(...)` — нажатия инлайн-кнопок;
- фильтры: `Command("x")`, `F.text == "..."`, `F.photo`, `F.data.startswith("a:")`;
- `core.Database` — SQLite: `execute / query / one`;
- `core.is_admin(user_id)` — проверка по `ADMIN_IDS`.

## Как сделать свой бот на основе шаблона

1. Скопируйте ближайший по смыслу файл: `cp bots/bot03_todo.py bots/my_bot.py`.
2. Поменяйте тексты, данные (`CATALOG`, `QUESTIONS`, `PAGES`, `SYSTEM_PROMPT`) и хендлеры.
3. Запустите: `python -m bots.my_bot`.
4. Хотите объединить функции? Передайте несколько роутеров: `run_bot(menu.router, todo.router)`.

## Тесты

```bash
python -m pytest bots
```

Тесты не ходят в сеть: `tests/conftest.py` подменяет Telegram «поддельной» сессией
и прогоняет настоящие хендлеры. Копируйте шаблон теста из `tests/test_bots.py`.

## Заметки по эксплуатации

- Состояния FSM и игры (боты 2, 5, 10) хранятся **в памяти** — при перезапуске сбросятся.
  Для постоянства используйте `core.Database` или `RedisStorage` из aiogram.
- Никогда не коммитьте `.env` (он уже в `.gitignore`).
- Для продакшена вместо long polling можно подключить вебхуки (документация aiogram).
